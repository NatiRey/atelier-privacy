POLÍTICA DE PRIVACIDAD Y TÉRMINOS DE USO – ARTELIER

Última actualización: abril de 2026

Artelier respeta la privacidad del usuario. Este documento explica qué información puede registrarse en la aplicación, cómo se gestiona dentro del dispositivo, qué funciones pueden generar copias adicionales de los datos y bajo qué condiciones se utiliza la app.

Artelier funciona principalmente de forma local en el dispositivo del usuario. Algunas funciones opcionales de respaldo, restauración o sincronización pueden habilitarse según la versión de la app, la configuración elegida por el usuario y las características activas del servicio.

1. Uso de la aplicación

Al utilizar Artelier, el usuario acepta las condiciones establecidas en este documento. Si no está de acuerdo, puede dejar de utilizar la aplicación en cualquier momento.

Artelier es una herramienta digital para la gestión de procesos, piezas, stock, pedidos, jornadas, tareas y otras actividades relacionadas con el trabajo de taller.

La descarga o compra de Artelier otorga una licencia de uso personal, no exclusiva e intransferible. Esto permite utilizar la app, pero no implica adquirir derechos sobre su desarrollo, su código ni sobre la disponibilidad futura de sus funcionalidades.

2. Información que registra el usuario

Artelier puede registrar información ingresada directamente por el usuario para el funcionamiento de la app, incluyendo:

Contactos seleccionados manualmente

La app solo accede a contactos que el usuario elige de forma puntual mediante el selector del sistema. No realiza lectura masiva de toda la agenda del dispositivo.

Datos manuales

Incluye, entre otros, clientes, pedidos, piezas, materiales, jornadas, tareas, movimientos de stock, recordatorios y otros registros cargados manualmente en la aplicación.

Archivos adjuntos

Incluye fotos, documentos, notas u otros archivos que el usuario agregue a piezas, stock, pedidos u otros registros similares.

Datos de respaldo y restauración

Artelier permite crear y restaurar respaldos locales por decisión del usuario.

3. Cómo se gestionan los datos

La base principal de datos de Artelier se almacena localmente en el dispositivo del usuario.

La versión pública actual funciona en modo local y ofrece respaldo/restauración local.

4. Dónde se almacenan los datos

La base de datos principal se guarda localmente en el dispositivo.

Si el usuario exporta un respaldo, el archivo se guarda en el destino que elija (por ejemplo, almacenamiento local, Drive u otro proveedor de archivos de su cuenta).

Ese destino es administrado por el usuario y por el proveedor elegido, bajo sus propias políticas.

5. Conservación de respaldos

Artelier no ofrece respaldo remoto automático administrado por la app.

6. Cómo se comparte la información

Artelier no vende ni comparte datos personales con terceros para fines publicitarios.

Los datos solo se transfieren cuando:

  • el usuario activa funciones compatibles de respaldo;
  • el usuario exporta una copia de seguridad;
  • el usuario restaura información en otro dispositivo;
  • el usuario comparte información de forma voluntaria mediante funciones del sistema o del dispositivo;
  • intervienen servicios externos necesarios para funciones opcionales activadas por el usuario.

7. Qué no hace Artelier con los datos

Artelier no vende datos personales.

Artelier no utiliza la información del usuario para perfilado publicitario dentro de la app.

Artelier no guarda archivos de audio propios al utilizar funciones de voz.

8. Permisos del dispositivo

Artelier utiliza permisos únicamente cuando son necesarios para funciones específicas de la aplicación.

Contactos del sistema

La app solo accede a contactos seleccionados manualmente por el usuario mediante el selector del sistema. No realiza lectura masiva de la agenda del dispositivo.

Micrófono (android.permission.RECORD_AUDIO)

Se utiliza únicamente cuando el usuario activa funciones de dictado o comandos por voz. Artelier no guarda archivos de audio propios; utiliza el reconocedor del sistema para convertir voz en texto o comandos. Si el usuario no otorga este permiso, puede continuar utilizando la app mediante ingreso manual.

Notificaciones (android.permission.POST_NOTIFICATIONS)

Se utilizan para mostrar recordatorios y alertas operativas. Son opcionales y pueden desactivarse en cualquier momento desde la configuración del dispositivo.

Servicios en primer plano (android.permission.FOREGROUND_SERVICE y android.permission.FOREGROUND_SERVICE_DATA_SYNC)

Permiten mantener activos procesos críticos relacionados con cronómetros, persistencia/restauración de estado y alertas operativas visibles mientras la app no está en primer plano.

Alarmas exactas (android.permission.SCHEDULE_EXACT_ALARM)

Permiten programar recordatorios puntuales para tareas o actividades del taller.

Archivos y multimedia

Se utilizan solo cuando el usuario decide importar, adjuntar, exportar o guardar archivos desde funciones de la app o del sistema.

Todos los permisos pueden ser gestionados por el usuario desde la configuración del dispositivo.

9. Seguridad

Artelier incorpora medidas técnicas orientadas a proteger la información registrada en la app.

Determinados datos sensibles, como teléfono, correo electrónico y dirección, pueden almacenarse cifrados dentro del dispositivo.

Además, las copias de respaldo y los procesos de sincronización compatibles pueden generarse cifrados.

Para estas funciones se utilizan mecanismos criptográficos como AES/GCM y protección de claves mediante Android Keystore.

Esto no significa que toda la información de la app se encuentre cifrada en cualquier contexto o en todos los flujos posibles, sino que el cifrado se aplica especialmente a ciertos campos sensibles y a respaldos o sincronizaciones compatibles.

Los servicios externos solo intervienen cuando el usuario activa sincronización, restauración, respaldo o funciones relacionadas.

Se recomienda proteger el dispositivo con código, patrón, contraseña o biometría.

Si bien se aplican medidas de seguridad razonables, ningún sistema informático puede garantizar una protección absoluta frente a accesos no autorizados, pérdida de información, fallas técnicas o eventos externos fuera del control razonable del titular.

10. Control y eliminación de datos

El usuario puede editar o eliminar registros desde la aplicación, revocar permisos del sistema y desactivar la sincronización cuando lo desee.

Si el usuario desinstala Artelier, se elimina del dispositivo la base de datos local de la app, salvo que existan copias externas exportadas o respaldos generados fuera del dispositivo.

Las copias exportadas manualmente o los respaldos externos generados por el usuario pueden permanecer hasta que este los elimine manualmente o solicite su eliminación, según corresponda.

El usuario es responsable de gestionar y eliminar las copias exportadas manualmente en los destinos que haya elegido.

Los registros de diagnóstico, como reportes de errores, permanecen en el dispositivo hasta que el usuario decida compartirlos con soporte.

Si el usuario desea solicitar la eliminación de datos sincronizados o de copias conservadas por respaldo o soporte, puede escribir al correo de contacto indicado en este documento o en Play Store o llenar el formulario.

11. Menores de edad

Artelier no está dirigida principalmente a menores de 13 años.

Si se detectan datos personales de un menor sin consentimiento de su responsable legal, podrá solicitarse su eliminación mediante el canal de contacto indicado en este documento.

12. Derechos del usuario

El usuario puede retirar permisos desde la configuración del dispositivo y controlar, cuando corresponda, qué información se sincroniza o respalda.

También puede solicitar la eliminación de datos sincronizados o respaldados cuando corresponda.
