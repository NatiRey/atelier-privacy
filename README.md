# Artelier Privacy Policy

Este repositorio contiene una página HTML estática con la política de privacidad y términos de uso de Artelier.

## Publicar un link público con GitHub Pages

1. Subí este repo a GitHub.
2. En GitHub, abrí **Settings > Pages**.
3. En **Build and deployment**, elegí:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` (o la rama principal) y carpeta `/ (root)`
4. Guardá los cambios.
5. Esperá 1 a 3 minutos y abrí el link que muestra GitHub Pages.

El enlace público normalmente queda así:

`https://<tu-usuario>.github.io/<nombre-del-repo>/`

Como el archivo es `index.html`, la página abre directamente en esa URL.
